## Project Overview

This project uses ServiceNow Flow Designer to automate the Standard Laptop procurement workflow. After approval of a Standard Laptop request, a Catalog Task is automatically created and assigned to the Hardware team for configuration.

## Workflow

User → Service Catalog → Standard Laptop → Order Now → Service Request → Requested Item → Approval → Approved → Flow Designer → Create Catalog Task → Hardware Team → Laptop Configuration
